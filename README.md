# mirza-ping

این سایت تست سرعت ساخته شده توسط dashbehrad یکی حمایت کنندگان اینترنت آزاد هست

این سایت برای تست پینگ و جیتر و سرعت دانلود هست که برای اینترنت جهانی بهینه شده و از سرور های گوگل و والتر استفاده میکنه 

لینک سایت: https://dashbehrad.github.io/mirza-ping/

لطفا از این پروژه حمایت کنید و منتظر آپدیت ها باشید.
